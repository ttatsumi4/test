# 旅行スケジュール管理アプリ

シンプルで使いやすい旅行スケジュール管理アプリケーションです。

## 機能

- ✅ 予定の追加（名称、開始時間、終了時間、備考）
- ✅ 予定の編集
- ✅ 予定の削除
- ✅ 開始時間順に自動ソート
- ✅ ローカルストレージに自動保存
- ✅ レスポンシブデザイン（スマートフォン対応）

## 使い方

1. `index.html` をWebブラウザで開きます
2. フォームに以下の情報を入力します：
   - **予定名**: 予定のタイトル（例: 東京タワー観光）
   - **開始時間**: 予定の開始日時
   - **終了時間**: 予定の終了日時
   - **備考**: メモや詳細情報（任意）
3. 「追加」ボタンをクリックして予定を保存
4. 予定一覧から「編集」または「削除」が可能

## ファイル構成

- `index.html` - アプリケーションのメインHTML
- `style.css` - スタイルシート
- `app.js` - アプリケーションロジック

## 技術仕様

- 純粋なHTML/CSS/JavaScript（フレームワーク不要）
- ローカルストレージでデータ永続化
- モダンなUI/UX
- バリデーション機能付き

## ブラウザ要件

- モダンなWebブラウザ（Chrome、Firefox、Safari、Edge等）
- JavaScript有効化必須
- ローカルストレージサポート必須
